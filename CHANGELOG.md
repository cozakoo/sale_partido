## [0.0.1] - 2026-05-30

### Added
- Initial project setup with Java 21, Spring Boot 4.0.6, Angular 20.3
- User authentication and authorization (JWT)
- PostgreSQL and Redis integration
- Kubernetes deployment manifests
- GitHub Actions CI/CD (SonarQube, Playwright E2E tests)
- RESTful API with OpenAPI/Swagger documentation
- Material Design UI with Bootstrap 5
- JUnit 5 testing with Mockito and TestContainers

### Infrastructure
- Docker containers for backend, frontend, PostgreSQL, Redis
- Kubernetes manifests with configmaps and secrets
- Self-hosted GitHub Actions runner
- SonarQube code quality analysis
