# QA Checklist - E5-H01: Calendario de Disponibilidad

**Rápida referencia para QA Engineers**

---

## Pre-Pruebas

### Ambiente
- [ ] Backend corriendo en http://localhost:8080
- [ ] Frontend corriendo en http://localhost:4200
- [ ] Base de datos con datos de prueba cargados
- [ ] No hay errores en consola (F12)
- [ ] Network sin red flag (F12 → Network)

### Datos
- [ ] Al menos 1 Local configurado
- [ ] Al menos 1 Cancha por Local
- [ ] Horarios configurados (ej: 09:00-22:00)
- [ ] 2+ turnos LIBRES en próxima semana
- [ ] 2+ turnos OCUPADOS en próxima semana
- [ ] 10+ turnos históricos para historial

## Escenario 1: Disponibilidad Semanal

```
Ruta: Locales → [Local] → [Cancha] → Ver Disponibilidad
```

### Renderizado
- [ ] Calendario carga sin errores
- [ ] 7 columnas (Lunes-Domingo)
- [ ] Fechas se muestran correctamente
- [ ] Horarios están visibles

### Datos
- [ ] Turnos LIBRES mostrados en verde
- [ ] Turnos OCUPADOS mostrados en rojo
- [ ] Cantidad de turnos es correcta
- [ ] Horarios fuera de servicio grises

### Interacción
- [ ] Click "Siguiente semana" → cambio visible
- [ ] Click "Semana anterior" → cambio visible
- [ ] NO permite ir a fecha pasada
- [ ] Hover muestra tooltip

**Estado: [ ] PASS [ ] FAIL**

## Validaciones Técnicas

### API Backend

```bash
# Copiar y ejecutar en terminal
curl -s "http://localhost:8080/locales/[uuid]/disponibilidad?fechaInicio=2026-06-01&fechaFin=2026-06-07" | jq .
```

- [ ] HTTP 200
- [ ] Response es JSON válido
- [ ] Array de turnos
- [ ] Estructura correcta:
  ```json
  {
    "canchaUuid": "...",
    "canchaNombre": "...",
    "turnos": [
      {
        "fecha": "YYYY-MM-DD",
        "horaInicio": "HH:mm",
        "horaFin": "HH:mm",
        "estado": "LIBRE|OCUPADO",
        "reserva": {...} // si OCUPADO
      }
    ]
  }
  ```

### Console (F12 → Console)
- [ ] Sin errores rojos (console.error)
- [ ] Sin warnings críticos
- [ ] Network requests exitosos

### Performance (F12 → Performance)
- [ ] FCP < 2s
- [ ] LCP < 3s
- [ ] INP < 200ms
- [ ] API responde < 500ms

**Estado: [ ] PASS [ ] FAIL**
